# Rajitan（らじたん）スケジューリング機能詳細設計書

## 1. 概要

### 1.1 目的
Rajitanにおけるスケジューリング機能は、ユーザーが自然言語でスケジュール設定を行い、指定された時間に自動的に各種機能（要約、クイズ、音楽推薦）を実行する仕組みを提供します。

### 1.2 設計思想
- **自然言語による設定**: ユーザーが直感的にスケジュールを設定できる
- **確認フロー**: 設定時には必ず確認を行い、誤操作を防止
- **柔軟な実行**: 定期実行と一時実行の両方に対応
- **可視化**: 設定されたスケジュールを一覧で確認可能

## 2. 機能要件

### 2.1 スケジューリング種類

#### 2.1.1 定期スケジューリング
- **毎時実行**: 毎時○○分に実行
- **毎日実行**: 毎日○○時○○分に実行
- **毎週実行**: 毎週○曜日の○○時○○分に実行
- **毎月実行**: 毎月○○日の○○時○○分に実行

#### 2.1.2 一時スケジューリング
- **特定日時実行**: YYYY/MM/DD HH:MM の形式で指定
- **相対時間実行**: 「30分後」「1時間後」などの相対指定

### 2.2 対象機能
- **要約機能**: 過去の会話を要約して投稿
- **クイズ機能**: 会話内容に基づくクイズを出題
- **音楽推薦機能**: 現在の雰囲気に合った音楽を推薦
- **カスタムメッセージ**: ユーザー指定のメッセージを投稿

### 2.3 自然言語処理
以下のような自然言語での指示に対応：
- 「19:00から、オススメの音楽を尋ねるようにして」
- 「毎日18時に今日の会話をまとめて」
- 「毎週月曜日の朝9時にクイズを出して」
- 「30分後に会話の要約をして」

```python
async def parse_schedule_request(self, user_input: str) -> ScheduleParseResult:
    """
    自然言語入力からスケジュール情報を抽出
    """
    # OpenAI APIを使用して意図を解析
    prompt = f"""
    以下のメッセージからスケジュール設定の情報を抽出してください：
    
    入力: {user_input}
    
    抽出する情報：
    - 実行時間（具体的な時刻または相対時間）
    - 実行機能（要約、クイズ、音楽推薦、カスタムメッセージ）
    - 実行パターン（一回限り、毎日、毎週、毎月）
    - 追加情報（曜日、日付など）
    
    JSON形式で返してください。
    """
    
    # API呼び出しとレスポンス解析
    response = await self.openai_client.parse_schedule_intent(prompt)
    return ScheduleParseResult.from_dict(response)
```

### 4.2 スケジュール実行

#### 4.2.1 定期実行の管理
```python
async def check_and_execute_schedules(self):
    """
    定期的にスケジュールをチェックして実行
    """
    current_time = datetime.now()
    
    # 実行対象のスケジュールを取得
    schedules = await self.get_executable_schedules(current_time)
    
    for schedule in schedules:
        try:
            # 機能実行
            await self.execute_schedule(schedule)
            
            # 次回実行時刻の計算
            next_execution = self.calculate_next_execution(schedule)
            await self.update_schedule_execution(schedule.id, current_time, next_execution)
            
        except Exception as e:
            logger.error(f"Schedule execution failed: {e}")
            await self.handle_execution_error(schedule, e)
```

#### 4.2.2 機能実行の制御
```python
async def execute_schedule(self, schedule: ScheduleInfo):
    """
    スケジュールに基づいて機能を実行
    """
    channel = self.bot.get_channel(int(schedule.channel_id))
    if not channel:
        raise ValueError(f"Channel {schedule.channel_id} not found")
    
    if schedule.target_function == "summary":
        await self.execute_summary_function(channel, schedule)
    elif schedule.target_function == "quiz":
        await self.execute_quiz_function(channel, schedule)
    elif schedule.target_function == "music":
        await self.execute_music_function(channel, schedule)
    elif schedule.target_function == "custom":
        await self.execute_custom_message(channel, schedule)
```

```python
async def show_schedule_list(self, channel_id: str) -> discord.Embed:
    """
    設定されたスケジュール一覧を表示
    """
    schedules = await self.get_channel_schedules(channel_id)
    
    embed = discord.Embed(
        title="📅 設定されたスケジュール一覧",
        color=0x0099ff
    )
    
    for schedule in schedules:
        status = "🟢 アクティブ" if schedule.is_active else "🔴 停止中"
        next_run = schedule.next_execution.strftime("%Y/%m/%d %H:%M") if schedule.next_execution else "未定"
        
        embed.add_field(
            name=f"{schedule.target_function} ({schedule.schedule_type})",
            value=f"次回実行: {next_run}\n状態: {status}",
            inline=False
        )
    
    return embed
```

## 5. データベース設計

### 5.1 スケジュールテーブル拡張
```sql
CREATE TABLE schedules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    channel_id TEXT NOT NULL,
    guild_id TEXT NOT NULL,
    schedule_type TEXT NOT NULL,  -- 'PERIODIC', 'ONE_TIME'
    target_function TEXT NOT NULL,  -- 'summary', 'quiz', 'music', 'custom'
    custom_message TEXT,
    
    -- 実行パターン
    pattern_type TEXT NOT NULL,  -- 'hourly', 'daily', 'weekly', 'monthly', 'once'
    hour INTEGER,
    minute INTEGER,
    day_of_week INTEGER,  -- 0=Monday, 6=Sunday
    day_of_month INTEGER,
    specific_datetime TIMESTAMP,
    
    -- 管理情報
    is_active BOOLEAN DEFAULT TRUE,
    created_by TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_executed TIMESTAMP,
    next_execution TIMESTAMP,
    
    FOREIGN KEY (channel_id) REFERENCES channels(id),
    FOREIGN KEY (guild_id) REFERENCES guilds(id)
);
```

### 5.2 実行履歴テーブル
```sql
CREATE TABLE schedule_executions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    schedule_id INTEGER NOT NULL,
    executed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status TEXT NOT NULL,  -- 'SUCCESS', 'FAILED', 'SKIPPED'
    error_message TEXT,
    execution_time_ms INTEGER,
    
    FOREIGN KEY (schedule_id) REFERENCES schedules(id)
);
```

## 7. エラーハンドリング

### 7.1 エラー種別
- **解析エラー**: 自然言語の解析に失敗
- **実行エラー**: スケジュール実行時のエラー
- **権限エラー**: 設定権限不足
- **システムエラー**: データベース接続エラーなど

### 7.2 エラー対応
```python
async def handle_schedule_error(self, error: Exception, schedule: ScheduleInfo):
    """
    スケジュール実行エラーの処理
    """
    # エラーログの記録
    logger.error(f"Schedule execution failed: {error}")
    
    # 実行履歴に記録
    await self.record_execution_result(schedule.id, "FAILED", str(error))
    
    # 管理者への通知（重要なエラーの場合）
    if isinstance(error, CriticalError):
        await self.notify_administrators(schedule, error)
    
    # 自動復旧の試行
    if schedule.auto_retry:
        await self.schedule_retry(schedule)
```
