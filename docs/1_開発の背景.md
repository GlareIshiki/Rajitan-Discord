# らじたん開発の背景

人とAIが会話していると、気がつくととめどなく続いてしまうことがある。技術的な話から雑談まで、なんでも答えてくれるのは確かに便利だ。でも会話が終わったあと、「あれ、最初何の話してたっけ？」となることが多い。
なんとなく腹落ちした感覚だけが残って、具体的に何を話したのか、何を学んだのかが曖昧になってしまう。会話はしているけれど、記憶に残らない。これって、会話に区切りがないからなんじゃないかと思った。
ラジオ番組を聞いていると、DJが絶妙なタイミングで「はーい、ここまでの話をまとめると〜」って言ったり、「番組の途中ですが、ここでクエスチョンです！」ってクイズを出したり、「今の気分にぴったりの曲がありますよ」って音楽を提案してくれる。このマスコットキャラみたいな存在が、ただの雑談を記憶に残る体験に変えているのだと気づいた。
実際にSlackやDiscordで似たような機能があるか調べてみると、確かに要約Bot、クイズBot、音楽推薦Botはそれぞれ存在していた。でも、これらはすべて「頼まれたら動く」受動的なツールだった。「要約して」と言われて要約する、「クイズ出して」と言われてクイズを出す。
それに対して、らじたんは会話の流れを読んで「そろそろまとめた方がいいかな？」「みんな話が盛り上がってきたから、クイズでもどう？」と能動的に提案する。これは単なる機能の違いではなく、情報を提供するツールから、会話体験そのものをデザインする存在への転換だと思う。
散漫になりがちなDiscord上の会話を、ラジオ番組のように構造化して、記憶に残る体験に変える。技術的には既存の技術の組み合わせだが、「会話体験全体をデザインする」というコンセプトで作られたプロダクトは見つからなかった。
らじたんの開発は、AIの技術を使いながら、人間のコミュニケーション自体をもっと豊かにしたいという想いから始まっている。ただ便利なツールを作るのではなく、人々の対話そのものが記憶に残る、意味のある体験になるような仕組みを作りたい。それが今回の開発の根本にある考えだ。
