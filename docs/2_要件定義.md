# Rajitan（らじたん）要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
**Rajitan（らじたん）** - Discord会話体験向上Bot

### 1.2 目的・背景
- Discord上での会話体験を「ラジオ番組風」に演出し、より記憶に残る対話を提供
- 従来の受動的なBotとは異なり、会話の流れを読んで能動的に介入する新しいタイプのBot
- 会話の散漫化を防ぎ、構造化された体験を通じてコミュニティの結束を強化

### 1.3 ターゲットユーザー
- **プライマリ**: ゲーミングコミュニティ、勉強会グループ、趣味のサーバー管理者
- **セカンダリ**: 企業の非公式Discordサーバー、オンライン学習グループ

## 2. 機能要件

### 2.1 必須機能（MVP）

#### 2.1.1 基本対話機能
- **キャラクター設定**: 管理者がシステムプロンプトを入力してキャラクター作成
- **対話応答**: メンション・スラッシュコマンドでの自然な会話
- **文脈理解**: 技術的な話題から雑談まで幅広く対応

#### 2.1.2 会話管理機能
- **会話監視**: 設定された時間間隔での会話内容収集
- **自動要約**: 会話の区切りで内容を整理・要約して提示
- **発動条件**: 会話がある場合のみ機能実行（無駄な介入を避ける）

#### 2.1.3 インタラクティブ機能
- **クイズ出題**: 会話内容に基づく10問のクイズ生成・実行
- **音楽推薦**: 会話の雰囲気に合わせた楽曲提案（事前確認付き）
- **タイミング制御**: ラジオDJ風の自然な進行管理

#### 2.1.4 設定管理機能
- **スケジュール設定**: 各機能の実行間隔をカスタマイズ可能
- **チャンネル別設定**: サーバー内の複数チャンネルで個別設定
- **権限管理**: 管理者のみが設定変更可能

### 2.2 任意機能（将来実装）

#### 2.2.1 高度な記憶機能
- **長期記憶**: キャラクターが過去の会話内容を記憶
- **学習機能**: ユーザーの好みや反応パターンの学習

#### 2.2.2 キャラクター拡張
- **プリセットキャラ**: 複数の定型キャラクターから選択
- **ボイス対応**: 音声での応答機能

#### 2.2.3 外部連携
- **MCP統合**: Notion/Obsidianとの連携で会話記録保存
- **音楽再生**: Spotify/YouTube自動再生機能
- **カレンダー連携**: 定期イベントとの同期

## 3. 非機能要件

### 3.1 性能要件
- **応答時間**: 通常の対話は3秒以内、要約・クイズ生成は10秒以内
- **同時接続**: 最大50サーバー、各サーバー500ユーザーまで対応
- **稼働率**: 99%以上（月間ダウンタイム7時間以内）

### 3.2 セキュリティ要件
- **データ保護**: 会話内容の暗号化保存
- **API制限**: 各種APIの使用量制限管理
- **権限制御**: 設定変更権限の適切な制御

### 3.3 可用性要件
- **24時間稼働**: 継続的なサービス提供
- **障害復旧**: 自動再起動機能
- **ログ管理**: エラー・使用状況の記録

### 3.4 拡張性要件
- **モジュール設計**: 機能の個別追加・削除が容易
- **API設計**: 将来的な機能拡張に対応
- **多言語対応**: 日本語以外への対応準備

## 4. 技術要件

### 4.1 開発環境
- **言語**: Python 3.9+
- **フレームワーク**: Discord.py
- **AI API**: OpenAI GPT-4/Claude
- **データベース**: Redis（キャッシュ）、SQLite（設定保存）

### 4.2 外部API
- **Discord API**: Bot機能
- **OpenAI API**: 会話・要約・クイズ生成
- **YouTube Data API**: 音楽検索
- **Spotify Web API**: 音楽検索

### 4.3 インフラ
- **開発環境**: ローカル開発 + テスト用Discordサーバー
- **本番環境**: Railway/Heroku（Phase 1）、VPS（Phase 2）
- **モニタリング**: 基本ログ + 稼働監視

## 5. 制約条件

### 5.1 技術的制約
- Discord API制限（レート制限遵守）
- OpenAI API使用量制限
- 音楽API制限（著作権考慮）

### 5.2 予算制約
- 初期開発: API使用料月額$50以内
- 運用費用: 月額$100以内（50サーバー運用時）

### 5.3 法的制約
- Discord利用規約遵守
- 各種API利用規約遵守
- 音楽著作権への配慮（直接再生なし）

## 6. 開発スケジュール

### Phase 1: MVP開発（6-8週間）
- Week 1-2: 基本Discord Bot + キャラ設定
- Week 3-4: 会話機能 + 手動要約
- Week 5-6: 自動タイミング制御 + クイズ機能
- Week 7-8: 音楽推薦 + テスト・デバッグ

### Phase 2: 機能拡張（4-6週間）
- 高度な記憶機能
- プリセットキャラクター
- 外部連携準備

### Phase 3: 運用・改善（継続）
- ユーザーフィードバック対応
- パフォーマンス最適化
- 新機能追加
