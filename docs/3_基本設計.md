# Rajitan（らじたん）基本設計書

## 1. システム全体アーキテクチャ

### 1.1 アーキテクチャ概要
```
[Discord API] ←→ [Rajitan Bot] ←→ [External APIs]
                      ↓
               [Data Storage Layer]
```

### 1.2 レイヤー構成
- **Presentation Layer**: Discord インターフェース
- **Application Layer**: ビジネスロジック（会話管理、キャラクター制御）
- **Domain Layer**: コアドメイン（会話分析、コンテンツ生成）
- **Infrastructure Layer**: 外部API連携、データ永続化

### 1.3 外部システム連携
- **Discord API**: Bot機能、メッセージ送受信
- **OpenAI API**: 会話生成、要約、クイズ作成
- **YouTube Data API**: 音楽検索
- **Spotify Web API**: 音楽メタデータ取得
- **Redis**: セッション管理、キャッシュ
- **SQLite**: 設定データ、統計情報

### 3.2 SQLite テーブル設計
```sql
-- サーバー設定
CREATE TABLE guilds (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- チャンネル設定
CREATE TABLE channels (
    id TEXT PRIMARY KEY,
    guild_id TEXT NOT NULL,
    name TEXT NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (guild_id) REFERENCES guilds(id)
);

-- キャラクター設定
CREATE TABLE characters (
    guild_id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    system_prompt TEXT NOT NULL,
    personality_traits TEXT, -- JSON
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (guild_id) REFERENCES guilds(id)
);

-- スケジュール設定
CREATE TABLE schedules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    channel_id TEXT NOT NULL,
    feature_type TEXT NOT NULL, -- 'summary', 'quiz', 'music'
    interval_minutes INTEGER NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    last_executed TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (channel_id) REFERENCES channels(id)
);

-- 使用統計
CREATE TABLE usage_stats (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    guild_id TEXT NOT NULL,
    channel_id TEXT NOT NULL,
    feature_type TEXT NOT NULL,
    execution_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    success BOOLEAN DEFAULT TRUE,
    FOREIGN KEY (guild_id) REFERENCES guilds(id)
);
```

## 5. シーケンス設計

### 5.1 通常対話フロー
```
User → Discord: メンション/スラッシュコマンド
Discord → RajitanBot: メッセージイベント
RajitanBot → ConversationTracker: メッセージ記録
RajitanBot → CharacterManager: 応答生成要求
CharacterManager → OpenAI API: プロンプト送信
OpenAI API → CharacterManager: 応答取得
CharacterManager → RajitanBot: キャラクター応答
RajitanBot → Discord: 応答メッセージ送信
```

### 5.2 自動機能実行フロー
```
SchedulerManager: 定期チェック実行
SchedulerManager → ConversationTracker: 会話状況確認
ConversationTracker → SchedulerManager: アクティブ状況返却
SchedulerManager → FeatureExecutor: 機能実行要求
FeatureExecutor → ContentGenerator: コンテンツ生成
ContentGenerator → OpenAI API: 生成要求
OpenAI API → ContentGenerator: 生成結果
ContentGenerator → FeatureExecutor: コンテンツ返却
FeatureExecutor → Discord: 結果投稿
```

## 7. エラーハンドリング設計

### 7.1 エラー分類
- **システムエラー**: Discord API制限、外部API障害
- **ビジネスエラー**: 不正なコマンド、権限不足
- **データエラー**: DB接続失敗、データ不整合

### 7.2 リトライ戦略
- **API呼び出し**: 指数バックオフ（最大3回）
- **DB操作**: 即座にリトライ（最大2回）
- **Discord投稿**: 1秒待機後リトライ（最大3回）

## 8. セキュリティ設計

### 8.1 認証・認可
- **Bot認証**: Discord Bot Token
- **権限管理**: Discord権限システム活用
- **設定変更**: 管理者権限要求

### 8.2 データ保護
- **環境変数**: API Key等の機密情報
- **会話データ**: 24時間後自動削除
- **ログデータ**: 個人識別情報マスキング

## 9. パフォーマンス設計

### 9.1 最適化方針
- **非同期処理**: asyncio活用
- **キャッシュ**: Redis活用で応答高速化
- **バッチ処理**: API呼び出し削減

### 9.2 制限設定
- **同時実行**: チャンネル別最大1機能実行
- **レート制限**: Discord API制限遵守
- **メモリ使用**: 会話履歴適切な削除
