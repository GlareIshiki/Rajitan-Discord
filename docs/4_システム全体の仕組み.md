# 4. システム全体の仕組み

## 4.1 システム概要

Rajitan Discord Botは、Discordサーバー内でAIキャラクターとして動作し、会話の追跡、要約、クイズ生成、音楽推薦などの機能を提供する包括的なチャットボットシステムです。

### 4.2.2 主要コンポーネント

#### 1. Bot Client (`rajitan/bot/client.py`)
- **役割**: Discord APIとの通信、メッセージ処理、コマンド実行
- **主要機能**:
  - メッセージの受信と解析
  - メンション機能の処理
  - スラッシュコマンドの実行
  - エラーハンドリング

#### 2. Character Manager (`rajitan/character/manager.py`)
- **役割**: AIキャラクターの管理と応答生成
- **主要機能**:
  - キャラクターの作成・更新
  - 性格設定の管理
  - OpenAI APIを使用した応答生成
  - キャラクター情報の永続化

#### 3. Conversation Tracker (`rajitan/conversation/tracker.py`)
- **役割**: 会話の追跡と分析
- **主要機能**:
  - メッセージの記録
  - 会話履歴の管理
  - 会話状態の分析
  - 参加者情報の追跡

#### 4. Conversation Summarizer (`rajitan/conversation/summarizer.py`)
- **役割**: 会話の要約生成
- **主要機能**:
  - 会話内容の要約
  - 重要ポイントの抽出
  - 要約のフォーマット

#### 5. Quiz Generator (`rajitan/features/quiz/generator.py`)
- **役割**: 会話ベースのクイズ生成
- **主要機能**:
  - 会話内容からの問題作成
  - 選択肢の生成
  - 正解と解説の提供

#### 6. Quiz Runner (`rajitan/features/quiz/runner.py`)
- **役割**: クイズの実行と管理
- **主要機能**:
  - クイズの開始・終了
  - 回答の処理
  - スコアの管理

#### 7. Scheduler Manager (`rajitan/scheduler/manager.py`)
- **役割**: 自動実行機能の管理
- **主要機能**:
  - スケジュールタスクの管理
  - 定期的な機能実行
  - 通知機能の制御

## 4.3 データフロー

### 4.3.1 メッセージ処理フロー

```
1. Discord API → メッセージ受信
2. Bot Client → メッセージ解析
3. Conversation Tracker → 会話記録
4. Character Manager → 応答生成
5. OpenAI API → AI応答取得
6. Bot Client → 応答送信
7. Conversation Tracker → 応答記録
```

### 4.3.2 メンション処理フロー

```
1. ユーザー → @Rajitan メンション
2. Bot Client → メンション検出
3. メッセージ内容 → メンション除去
4. Conversation Tracker → 会話履歴取得
5. Character Manager → 応答生成
6. Bot Client → 応答送信
```

### 4.3.3 コマンド処理フロー

```
1. ユーザー → /コマンド実行
2. Discord API → インタラクション受信
3. Bot Client → コマンド解析
4. 対応する機能 → 処理実行
5. Bot Client → 結果送信
```

## 4.4 データベース設計

### 4.4.1 SQLiteデータベース

#### Guilds テーブル
```sql
CREATE TABLE guilds (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### Characters テーブル
```sql
CREATE TABLE characters (
    guild_id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    system_prompt TEXT,
    personality_traits TEXT,  -- JSON形式
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (guild_id) REFERENCES guilds(id)
);
```

#### Schedules テーブル
```sql
CREATE TABLE schedules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    channel_id TEXT NOT NULL,
    feature_type TEXT NOT NULL,  -- 'summary', 'quiz', 'music'
    interval_minutes INTEGER NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    last_executed TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 4.4.2 Redisキャッシュ

#### 会話データ
- **キー**: `conversation:{channel_id}`
- **内容**: 会話履歴、参加者情報、メッセージ数
- **TTL**: 24時間

#### アクティブセッション
- **キー**: `session:{channel_id}`
- **内容**: 現在の会話状態、最後の活動時間
- **TTL**: 1時間

#### 機能履歴
- **キー**: `feature_history:{channel_id}:{feature}`
- **内容**: 機能の実行履歴、最後の実行時間
- **TTL**: 7日

## 4.5 主要機能詳細

### 4.5.1 メンション機能

#### 処理手順
1. **メンション検出**: `self.user in message.mentions`
2. **メッセージ解析**: メンション部分の除去
3. **会話履歴取得**: 過去30分の会話を取得
4. **応答生成**: OpenAI APIを使用
5. **応答送信**: Discordチャンネルに送信

#### エラーハンドリング
- Redis接続エラー時のフォールバック処理
- 会話履歴取得失敗時の継続処理
- 応答生成失敗時のデフォルトメッセージ

### 4.5.2 スラッシュコマンド

#### 実装済みコマンド
- `/setup`: キャラクター設定
- `/status`: Bot状態表示
- `/chat`: 直接チャット
- `/summary`: 会話要約
- `/quiz`: クイズ開始
- `/help`: ヘルプ表示

#### コマンド処理
1. **権限チェック**: ユーザーの権限確認
2. **入力検証**: パラメータの妥当性確認
3. **処理実行**: 対応する機能の実行
4. **結果送信**: 処理結果の送信

### 4.5.3 自動機能

#### スケジューラー機能
- **定期実行**: 設定された間隔での自動実行
- **機能タイプ**: summary, quiz, music
- **実行条件**: 会話の活発度、時間間隔
- **通知機能**: Discordチャンネルへの自動投稿

#### 実行フロー
1. **スケジュール確認**: データベースから実行予定を取得
2. **条件チェック**: 実行条件の確認
3. **機能実行**: 対応する機能の実行
4. **結果通知**: Discordチャンネルへの通知
5. **履歴更新**: 実行履歴の更新

## 4.6 設定とカスタマイズ

### 4.6.1 キャラクター設定

#### 性格タイプ
- **default**: バランスの取れた性格
- **cheerful**: 明るく活発
- **calm**: 落ち着いてリラックス
- **witty**: 機知に富んだ
- **professional**: フォーマルでビジネスライク
- **friendly**: 親しみやすく温かい
- **sarcastic**: 皮肉とユーモア

#### カスタマイズ要素
- **システムプロンプト**: カスタム設定可能
- **性格特性**: 各タイプの詳細設定
- **応答スタイル**: 温度、トークン数、ペナルティ

### 4.6.2 通知設定

#### 設定可能項目
- **機能タイプ**: summary, quiz, music
- **実行間隔**: 5分〜1440分（24時間）
- **有効/無効**: 機能のON/OFF切り替え
- **チャンネル指定**: 特定チャンネルでの実行

## 4.7 エラーハンドリング

### 4.7.1 エラー種別

#### 接続エラー
- **Discord API**: 接続失敗、レート制限
- **OpenAI API**: API制限、認証エラー
- **Redis**: 接続失敗、タイムアウト
- **SQLite**: データベースエラー

#### 処理エラー
- **応答生成**: AI応答の失敗
- **データ処理**: データ形式エラー
- **権限エラー**: ユーザー権限不足

### 4.7.2 エラー対応

#### フォールバック処理
- **Redis接続失敗**: メモリキャッシュに切り替え
- **OpenAI API失敗**: デフォルト応答の使用
- **データベースエラー**: ログ出力と処理継続

#### ログ出力
- **エラーレベル**: ERROR, WARNING, INFO, DEBUG
- **ログファイル**: `logs/rajitan.log`
- **ログ内容**: エラー詳細、スタックトレース、コンテキスト情報
