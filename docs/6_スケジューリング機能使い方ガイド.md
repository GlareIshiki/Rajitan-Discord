## 🎯 基本的な使い方

### スケジューリング機能とは？
Rajitanのスケジューリング機能は、**2つの方法**で利用できます：

#### 🧠 方法1: 自然言語（推奨）
```
@らじたん 19:00に音楽をおすすめして
@らじたん 毎日18時に今日の会話をまとめて  
@らじたん 30分後にクイズを出して
```

#### ⚙️ 方法2: スラッシュコマンド
```
/setup - キャラクター設定
/chat - プライベートチャット
/summary - 手動で要約実行
/quiz - 手動でクイズ開始
/status - ボット状態表示
/help - ヘルプ表示
```

### 対応機能
- **📝 要約機能**: 過去の会話をまとめて投稿
- **🧩 クイズ機能**: 会話内容に基づくクイズを出題
- **🎵 音楽推薦**: 現在の雰囲気に合った音楽を推薦
- **💬 カスタムメッセージ**: 指定したメッセージを投稿

### 実行パターン
1. **定期実行**: 毎日、毎週、毎月など定期的に実行
2. **一時実行**: 特定の日時に一度だけ実行

## 🛠️ スラッシュコマンド一覧

### `/setup` - キャラクター設定
**説明**: サーバー用のキャラクターを設定します

**パラメータ**:
- `name` (オプション): キャラクター名（デフォルト: "Rajitan"）
- `personality` (オプション): 性格タイプ
  - `default` - 標準的な性格
  - `cheerful` - 明るく元気な性格
  - `calm` - 落ち着いた穏やかな性格
  - `witty` - ウィットに富んだ機知に富む性格
- `system_prompt` (オプション): カスタムシステムプロンプト

**使用例**:
```
/setup name:らじたん personality:cheerful
/setup name:助手 system_prompt:あなたは親切なアシスタントです
```

**権限**: 管理者権限が必要

---

### `/chat` - プライベートチャット  
**説明**: あなただけに見える形でキャラクターと会話します

**パラメータ**:
- `message` (必須): 送信するメッセージ

**使用例**:
```
/chat message:こんにちは！調子はどう？
/chat message:今日のスケジュールを確認したい
```

**特徴**:
- ✅ **プライベート**: 他のユーザーには見えません（ephemeral=True）
- 🎯 **即座に応答**: 確認なしで直接返答
- 📝 **履歴記録**: 会話履歴として記録されます（[PRIVATE]タグ付き）

---

### `/summary` - 手動要約実行
**説明**: 現在のチャンネルの会話を手動で要約します

**パラメータ**: なし

**使用例**:
```
/summary
```

**動作**:
1. 最近の会話データを取得
2. AI要約を生成  
3. 美しいフォーマットで表示

**注意**: 会話データが不足している場合は要約できません

---

### `/quiz` - 手動クイズ開始
**説明**: 会話内容に基づいてクイズを開始します

**パラメータ**: なし

**使用例**:
```
/quiz
```

**動作**:
1. 過去1時間の会話を分析
2. 10問のクイズを生成
3. インタラクティブなクイズを開始

**必要条件**: 最低15件のメッセージが必要

---

- 💬 会話統計（アクティブ状況、メッセージ数、参加者数）

## 💬 メンション機能（自然言語）

### 🧠 自動意図認識システム
`@らじたん` でメンションすると、メッセージの内容を自動分析し、適切な機能を実行します。

#### 📝 要約リクエスト（確認なし・即座実行）
以下のような表現で、**即座に要約**を実行：
```
@らじたん 今日の会話の内容を要約して
@らじたん ここまでの話をまとめて
@らじたん 会話の要約をお願いします
@らじたん サマリーを作って
```

#### ⏰ スケジュール設定（確認あり）
以下のような表現で、**確認付きスケジュール設定**：
```
@らじたん 19:00に音楽をおすすめして
@らじたん 毎日18時に会話をまとめて
@らじたん 30分後にクイズを出して
@らじたん 毎週月曜日の朝9時にクイズを出題して
```

#### 🧩 クイズリクエスト（即座実行）
```
@らじたん クイズを出して
@らじたん 問題を作って
@らじたん クイズゲームをしよう
```

#### 🎵 音楽推薦リクエスト（即座実行）
```
@らじたん 音楽をおすすめして
@らじたん 曲を教えて
@らじたん BGMを提案して
```

#### 💬 一般会話
上記以外のメッセージは一般会話として処理され、キャラクターが自然に応答します。

## ⚠️ トラブルシューティング

### よくある問題と解決方法

#### 1. ボットが反応しない
**原因:**
- ボットがオフライン
- チャンネル権限不足
- メンション形式が間違っている

**解決方法:**
1. `/status`でボットの状態を確認
2. ボットに必要な権限があるか確認
3. `@らじたん`（正確なメンション）を使用

#### 2. 自然言語が理解されない
**原因:**
- 曖昧な表現
- 対応していない機能名
- 信頼度が低い（70%未満）

**解決方法:**
1. より具体的な表現を使用：「要約して」「クイズを出して」
2. 標準的な機能名を使用
3. スラッシュコマンドで代替実行

#### 3. 要約・クイズが生成されない
**原因:**
- 会話データが不足している
- 会話内容が薄い

**解決方法:**
1. 要約：数件以上のメッセージが必要
2. クイズ：最低15件のメッセージが必要
3. より内容のある会話を行ってから再試行

#### 4. プライベートチャットが見える
**原因:**
- `/chat`以外のコマンドを使用
- メンションで話しかけている

**解決方法:**
1. `/chat message:内容`の形式を使用
2. メンションは全員に見えるパブリック機能

### エラーメッセージの対処

| エラーメッセージ | 原因 | 対処法 |
|-----------------|------|--------|
| 「最近の会話が見つからないよ」 | 会話データ不足 | もう少し話してから要約を依頼 |
| 「クイズを作るには、もう少し会話が必要だよ」 | メッセージ数不足 | 15件以上のメッセージ後に再試行 |
| 「スケジュール設定を理解できませんでした」 | 自然言語解析失敗 | より明確な表現で再入力 |
| 「エラーが発生しました」 | システムエラー | 少し待ってから再試行 |

## ❓ よくある質問

### Q1: スラッシュコマンドとメンションの違いは？
**A:** 
- **スラッシュコマンド**: 手動操作、即座に実行、技術的
- **メンション**: 自然言語、確認フロー、直感的

### Q2: プライベートチャット（/chat）の用途は？
**A:** 
- 個人的な質問や相談
- 他の人に見られたくない会話
- ボットの動作確認やテスト

### Q3: スケジュール設定で確認が出るのはなぜ？
**A:** 
- 誤解による意図しない設定を防ぐため
- 設定内容を明確に確認するため
- ただし要約は即座に実行（確認不要）

### Q4: 要約に必要な会話量は？
**A:** 
- 最低でも数件のメッセージが必要
- より良い要約には15-20件以上を推奨
- 会話の内容が薄い場合は要約をスキップ

### Q5: 現在使えるスラッシュコマンドは？
**A:** 以下の6つのコマンドが利用可能：
- `/setup` - キャラクター設定
- `/chat` - プライベートチャット
- `/summary` - 手動要約
- `/quiz` - 手動クイズ
- `/status` - ボット状態表示
- `/help` - ヘルプ表示

### Q6: スケジュール管理コマンドはありますか？
**A:** 現在のところ、スケジュール管理用の専用コマンドは実装されていません。将来のアップデートで追加予定です。

### Q7: エラーが発生した場合の通知は？
**A:** 
- 自動リトライ機能あり（最大3回）
- 連続失敗でスケジュール一時停止
- エラー詳細はログに記録

### Q8: タイムゾーンは？
**A:** 
- 日本時間（JST）で動作
- 「19:00」は日本の19:00として解釈

## 💡 Tips & Best Practices

### 🎯 効果的な使い方
